To-Do List App

Description

The To-Do List App is a simple task management application that allows users to create, read, update, and delete (CRUD) tasks. This app helps users stay organized and keep track of their daily activities.

Features

Add new tasks.

View a list of all tasks.

Edit existing tasks.

Mark tasks as completed.

Delete tasks.

USAGE: 

Open the app in your web browser or use the terminal interface.

Add, edit, or delete tasks as needed.

Technologies Used

Frontend: HTML, CSS, JavaScript
